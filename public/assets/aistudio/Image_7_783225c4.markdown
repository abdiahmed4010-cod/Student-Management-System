## Brand & Style

STUDENTLY is engineered for modern educational institutions, administrators, and bursars who demand precision, speed, and absolute clarity. The brand personality is authoritative yet approachable, striking a balance between rigorous financial compliance and intuitive student-facing interactions. The design style adopts a clean, minimal, Stripe- and Linear-inspired aesthetic characterised by high-contrast information density, crisp typography, and deliberate whitespace.

The UI evokes an emotional response of total control, trust, and calm efficiency. By removing administrative friction through restrained visual noise and predictable spatial choreography, the design system turns complex multi-tier fee structures, enrollment pipelines, and real-time ledger reconciliations into effortless daily workflows.

## Colors

The color palette is built for enterprise financial operations, prioritizing legibility, accurate status signaling, and immediate visual hierarchy. 

- **Primary (`#2563EB` - Royal Blue):** Drives primary actions, active states, key data highlights, and core interactive elements.
- **Secondary (`#EFF6FF` - Light Blue):** Used for subtle container fills, selected row states, and informative callout backgrounds.
- **Tertiary (`#172554` - Navy Text):** Commands utmost clarity for primary typography, headers, and navigation milestones.
- **Neutrals (`#F8FAFC` background, `#F1F5F9` Muted Surface, `#E2E8F0` Border, `#64748B` Secondary Text):** Establish a crisp canvas hierarchy with deliberate contrast steps that separate data tables, sidebar navigation, and card surfaces without relying on heavy shadows.

## Typography

Typography scales are calibrated specifically for dense financial dashboards and student records. Using Inter exclusively across all weights ensures absolute consistency and neutral legibility at small sizes. 

For mobile viewports, scale down headlines larger than 28px using the companion mobile tokens (`headline-lg-mobile` at 24px/32px) to prevent layout breaking on narrow screens. Data tables must utilize tabular figures (`font-variant-numeric: tabular-nums`) to ensure strict vertical alignment of currency values, invoice totals, and payment timestamps.

## Layout & Spacing

The layout philosophy follows a responsive 12-column fluid grid system paired with a strict 8px spatial baseline rhythm. This ensures predictable alignment across high-resolution desktop monitors used by finance teams down to mobile devices accessed by students on the move.

- **Grid Structure:** 12-column fluid container with fixed max-widths for desktop dashboards, 24px gutters, and 32px outer canvas margins.
- **Responsive Adaptations:** On tablet viewports, outer margins compress to 20px, and secondary sidebar navigation collapses into a slide-over drawer. On mobile devices, the grid collapses to a single column with 16px horizontal screen padding.
- **Spacing Application:** Component internal padding and spatial relationships must strictly reference the defined `space-*` scale to maintain rhythm across cards, tables, and form controls.

## Elevation & Depth

Depth is handled through low-contrast outlines and tonal surface layering rather than heavy drop shadows, aligning with the clean Stripe/Linear architectural language. 

- **Surfaces:** Use `#F8FAFC` as the foundational canvas, elevating cards and floating panels onto pure `#FFFFFF` surfaces bounded by crisp `#E2E8F0` borders.
- **Shadows:** Employ ultra-subtle, diffused ambient shadows (`0px 1px 2px rgba(15, 23, 42, 0.06), 0px 1px 3px rgba(15, 23, 42, 0.1)`) strictly for interactive overlays, dropdown menus, modals, and tooltips.
- **Focus States:** High-priority elements use a 2px Royal Blue ring offset by 2px of white background to signal active keyboard and pointer focus clearly without visual clutter.

## Shapes

The shape language reflects modern enterprise software ergonomics, utilizing intentional corner rounding between 10px and 14px. 

- **Containers & Cards:** Apply 12px border radius (`rounded-lg`) to data cards, modals, and input fields to soften the industrial density of financial ledgers.
- **Badges & Pills:** Fully rounded (pill-shaped) geometry with generous horizontal padding is reserved strictly for status indicators (e.g., *Paid*, *Overdue*, *Pending*) and user avatars.
- **Interactive Controls:** Buttons and dropdown triggers use 10px to 12px radii to ensure a tactile, responsive feel without appearing overly casual.

## Components

All components must leverage Lucide icons for visual anchoring, paired with the defined color, typography, and spacing tokens.

- **Buttons:** Available in Primary (Royal Blue background, white text), Secondary (Light Blue fill, Navy text), and Ghost (transparent background, hover surface tint). All variants include icon slots on left or right, maintaining 8px gap spacing and 10px corner radius.
- **Chips & Badges:** Compact status tags featuring subtle tinted backgrounds (e.g., soft green for *Paid*, soft amber for *Pending*, soft red for *Overdue*) paired with matching text weights and optional leading status dots.
- **Input Fields:** Clean border inputs featuring 12px rounding, `#E2E8F0` borders, and clear inline leading icons for search and filtering. Focus states instantly trigger a Royal Blue border and soft shadow ring.
- **Checkboxes & Radio Buttons:** Custom-built square and circular controls with 4px border radius for checkboxes, utilizing crisp check and dot vectors scaled precisely to 14px.
- **Cards & Data Tables:** Surfaces featuring white backgrounds, subtle borders, and generous padding. Data tables include sticky header rows, hover row highlighting in `#F1F5F9`, and right-aligned tabular figures for all monetary amounts.
- **Additional Components:** Command palette search modals, multi-step fee assignment wizards, metric summary stat cards with percentage change indicators, and student profile avatar clusters.
